# Migration guides

Each release with breaking changes has a guide in this folder.
Coding agents should use the `.agents.md` file, which lists the same changes as
mechanical rewrite rules.

| Migrating to | Guide | Agents |

| 8.0.0 | [8.0.0.md](8.0.0.md) | [8.0.0.agents.md](8.0.0.agents.md) |
| 5.0.0 | [5.0.0.md](5.0.0.md) | |

Skipping versions: apply the guides in order, oldest first.
